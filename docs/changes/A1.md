# A1: TripVault core

## Summary

Add per-member USDC ownership, bounded trip membership, personal automatic-spending
policies and creator-signed invitations. Ongoing joins implement the owner's
confirmed requirement without affecting anyone else's balance or purchases.

## Files

- packages/contracts/src/TripVault.sol
- packages/contracts/test/TripVault.core.t.sol
- packages/shared/src/abi.ts (generated)

## Interfaces touched

TripVault constructor, members/getBalance, deposit, setPolicy, join and inviteDigest.
The creator only authorizes membership; no administrative function can move funds.

## Verification

Foundry core tests cover personal accounting, non-members, invalid policies,
expired/replayed invitations, trip expiry and fuzzed deposits. Full workspace
checks and ABI generation run before commit.

## Follow-ups

A2–A4 implement proposals, verified approvals, delivery/refunds and withdrawals.
