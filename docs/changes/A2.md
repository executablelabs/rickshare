# A2: signed proposals and personal automatic approval

## Summary

Only the agent can submit proposals, and each proposal additionally needs an
allowlisted merchant's EIP-712 quote. Quotes bind title, location, price,
quantity, time, vault and chain, and are consumed once. Pending proposals do not
reserve funds; every participant's policy and available money is rechecked when
the complete proposal locks.

## Files

- packages/contracts/src/TripVault.sol
- packages/contracts/test/TripVault.proposals.t.sol
- packages/shared/src/abi.ts (generated)

## Interfaces touched

Quote/proposal structures; propose, getProposal, getShares, lock and reject;
Proposed, ShareChanged, Locked and Rejected events. B/A9 consume these additive APIs.

## Verification

Tests cover mixed consent, complete automatic locking, per-person cumulative
caps, policy revocation, unauthorized callers, quote replay/modification,
membership, sums, duplication and expiry. Full checks run before commit.
