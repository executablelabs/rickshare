# A3: wallet-bound verified approval attestations

## Summary

Add single-use EIP-712 approval attestations bound to the vault, chain, proposal,
member, exact share, nonce and expiry. A verifier signature alone cannot approve:
the participant's own wallet must call approve. Manual approval can exceed their
automatic cap, as confirmed by the owner.

## Files

- packages/contracts/src/TripVault.sol
- packages/contracts/test/TripVault.approvals.t.sol
- packages/shared/src/abi.ts (generated)

## Interfaces touched

approve, approvalDigest, approvalNonces and approvalExpiresAt. Pending getShares
returns effective consent after expiry/policy changes. Approval TTL is at most
15 minutes and cannot run beyond the purchase's delivery deadline.

## Verification

Tests cover signer/member/nonce mismatches, stale and overlong attestations,
double approval, verifier-only calls, cross-vault/chain replay and consent expiry
while waiting for another participant. Full workspace checks run before commit.
