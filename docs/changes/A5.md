# A5: vault factory and Arc deployment tooling

## Summary

Add a permissionless factory that fixes the token, agent, verifier and merchant
allowlist for every independent vault. The trip creator must be an initial
member. Add chain-checked deployment scripts and generate both contract ABIs.

## Files

- packages/contracts/src/TripFactory.sol and test/TripFactory.t.sol
- packages/contracts/script/Deploy.s.sol
- scripts/config.ts and scripts/deploy.ts
- Root script typecheck configuration and deployment command
- packages/shared/src/abi.ts (generated)

## Interfaces touched

Factory createTrip, isVault, vaultCount, paginated vaults and TripCreated event.
Deployment adds MERCHANT_1_ADDRESS, MERCHANT_2_ADDRESS and MERCHANT_3_ADDRESS to
the contract environment example. Root script dependencies (viem, Zod, shared
package and Bun types) support typed deployment and its configuration.

## Verification

Factory tests cover independent deployments, creator membership, fixed roles,
pagination and invalid configuration. Deployment checks the real chain id,
token decimals, fee floor and gas funding before sending. A public deployment
record is written only after a successful receipt.

## Follow-ups

Live Arc deployment requires a funded testnet deployer and configured role keys.
No deployed address is invented or inserted into arcTestnet.json before success.
