# A6: Arc clients and revocable SIWE sessions

## Summary

Add browser-bound single-use SIWE challenges and opaque server-side sessions.
Sign-in validates the domain, exact origin URI, chain, nonce and message time
before checking the wallet signature. Logout removes the database session.

## Files

- apps/api/src/modules/auth and modules/chain/clients.ts
- apps/api/src/db/schema.ts, client.ts and drizzle migrations
- apps/api/src/app.ts, config.ts and .env.example
- docs/API.md

## Interfaces touched

GET /auth/nonce, POST /auth/verify, GET /auth/session and POST /auth/logout.
Shared AuthEnv/session middleware supports subsequent authenticated modules.
Add AUTH_NONCE_TTL_SECONDS and SESSION_TTL_SECONDS environment settings.
The existing SESSION_SECRET becomes mandatory when using auth endpoints.

## Verification

Real EOA signatures exercise successful login/logout, challenge replay, wrong
wallet/application/chain, expiry, cross-origin rejection, browser binding and
service reconstruction. Arc's wallet verifier additionally supports EIP-1271;
live provider/network calls are replaced by the injected signature verifier in
unit tests. Full workspace checks run before commit.
