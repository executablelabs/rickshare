# B1: design primitives, app shell and ui gallery

## Summary

Add the web design system from docs/DESIGN.md: eight primitives (Button, Chip,
Amount, Avatar, AvatarStack, Field, Sheet, Toast), the trip app shell with a mobile
bottom nav and desktop left rail, and a `/dev/ui` gallery that shows every
primitive. Later Track B screens build on these instead of styling ad hoc.

## Files

- apps/web/package.json, bun.lock: vaul (sheets) and Phosphor (icons), both named
  in DESIGN.md; `@kitty/shared` workspace dependency for USDC decimals and `Member`.
- apps/web/src/lib/cx.ts: class name joiner used by every primitive.
- apps/web/src/lib/format-usd.ts: USDC base units to `$1,234.57`, bigint only,
  rounding half up to the cent.
- apps/web/src/lib/use-media-query.ts: desktop breakpoint hook for Sheet.
- apps/web/src/components/ui/{Button,Chip,Amount,Avatar,AvatarStack,Field,Sheet,Toast}.tsx
  and tests.
- apps/web/src/components/shell/AppShell.tsx and test: one `<nav>` that is a bottom
  tab bar below 1024px and a left rail above it, a 560px content column and an
  optional money panel.
- apps/web/src/routes/trips.$tripId.tsx: new layout route that wraps trip tabs in
  the shell.
- apps/web/src/routes/__root.tsx, index.tsx, dev.ui.tsx: root no longer renders
  `<main>` (the shell has its own); index and gallery render their own.
- apps/web/src/routeTree.gen.ts: regenerated by the router plugin.
- apps/web/src/styles/tokens.css: `--shadow-sheet` token, 200ms sheet timing, no
  sheet motion under `prefers-reduced-motion`.
- apps/web/src/gallery.test.tsx: gallery sections, sheet and toast smoke tests.
- docs/changes/B1-*.png: captures at 390 and 1280.

## Interfaces touched

None. The web routes are unchanged; `/trips/$tripId` is added as a layout route
around the existing trip tabs.
