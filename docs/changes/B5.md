# B5: trip agent module

## Summary

Add the trip agent: a Claude tool-use loop with six tools (`search_activities`,
`list_merchants`, `get_quote`, `get_trip_state`, `propose_purchase`,
`update_itinerary`), wrapping of untrusted content, and chat and itinerary
persistence. Model output can never name a payee: proposals reference a quote
fetched in the same turn, and that quote is submitted unchanged.

## Files

- apps/api/package.json, bun.lock: `@anthropic-ai/sdk` 1.6.0, the official SDK.
- apps/api/src/modules/agent/service.ts: `createAgentService().reply()` saves the
  member message, runs the loop and saves the reply. Model `claude-opus-5-5`,
  medium effort, prompt caching, server-side refusal fallbacks.
- apps/api/src/modules/agent/tools.ts: tool definitions (strict schemas), the
  `AgentPorts` the agent depends on, and the per-turn executor.
- apps/api/src/modules/agent/prompt.ts: system prompt.
- apps/api/src/modules/agent/untrusted.ts: `<untrusted_data>` wrapping.
- apps/api/src/modules/agent/schemas.ts: zod schemas for tool inputs and outside
  responses.
- apps/api/src/modules/agent/sources.ts: Tavily search and merchant catalog
  clients.
- apps/api/src/modules/agent/test-fixtures.ts: test-only trip, quote and fake
  ports.
- apps/api/src/modules/chat/service.ts: chat message store.
- apps/api/src/modules/trips/itinerary.ts: itinerary store.
- Tests next to each file.

## Interfaces touched

None beyond the tables added in the B5 interface PR (#3). `AgentPorts` names what
the agent expects from A9 (`submitProposal`), A10 (`getQuote`) and B3
(`getTripState`); those tasks supply the implementations.

## Verification

- bun run check: pass (api: 36 tests across 9 files).
- Acceptance: a search result containing a fake closing tag and instructions to
  pay another address reaches the model as one intact `untrusted_data` block. A
  scripted model that follows the instructions has both attempts rejected, and
  the only submitted proposal pays the allowlisted merchant.
- LLM, search and merchants are stubbed; no test calls a paid API.
