# D0: brand mark, loader and splash

## Summary

Rickshare now has a logo: an auto-rickshaw with two riders under one hood. The logo files are in `apps/web/public/brand/` and are also used as the favicon and home-screen icon. There is a rickshaw loader, which the router shows while a route is pending, and a splash for the first load of each session. In the splash the rickshaw drives in, then drives on and reveals "Rickshare" behind it. It is pure CSS, lasts under 2s, and is skipped under reduced motion.

## Files

- apps/web/public/brand/: mark (light, on dark), app icon (SVG, 512px, Apple touch), logo lockups (PNG)
- apps/web/index.html: favicon and Apple touch icon links
- apps/web/src/components/brand/RickshawMark.tsx: the mark as a component, wheels animatable
- apps/web/src/components/brand/Loader.tsx: loader with a status label, and RouteLoader
- apps/web/src/components/brand/Splash.tsx: once-per-session splash
- apps/web/src/styles/tokens.css: brand keyframes as Tailwind animate tokens
- apps/web/src/main.tsx, apps/web/src/router.ts: mount the splash, default pending component
- apps/web/src/routes/dev.ui.tsx: Brand and Loader sections in the gallery
- tests: Splash, Loader, brand-assets (public SVGs match the component), router, gallery

## Interfaces touched

None in code. The motion and brand rules are in the D0 interface change to docs/DESIGN.md.
