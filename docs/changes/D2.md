# D2: coral and navy tokens and primitives

## Summary

The web tokens now follow the coral and navy palette from D1. Primary buttons are coral and secondary buttons are white with a soft ring. Chips are tint fills with their own ink, and a new `action` tone covers "Waiting for you". Each member gets a stable avatar tint hashed from their address. Fields gain a hover ring, toasts gain status-tinted icons and the card shadow, and color changes ease only when motion is allowed.

## Files

- apps/web/src/styles/tokens.css: palette, band radius, card shadow
- apps/web/src/components/ui/{Button,Chip,Field,Sheet,Toast}.tsx: restyle
- apps/web/src/components/ui/{Avatar,AvatarStack}.tsx: member tints
- apps/web/src/components/ui/AvatarStack.test.tsx: tint tests
- apps/web/src/routes/dev.ui.tsx: action chip sample

## Interfaces touched

None. Component props only gain the optional `colorKey` on Avatar and the `action` Chip tone.
