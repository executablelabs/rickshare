# D3: navy app shell

## Summary

The trip shell now uses the coral and navy look. On mobile, a navy header band with rounded bottom corners shows the trip name, or the brand until trips load their names, and the active tab is a navy pill. On desktop, a navy rail carries the brand and the tabs, and the active tab has a coral marker. The browser bar matches the navy, and safe-area insets now apply on notched phones.

## Files

- apps/web/src/components/shell/AppShell.tsx: header band, tab pill, navy rail
- apps/web/src/components/ui/AvatarStack.tsx: `onInk` outline for the band
- apps/web/index.html: theme-color, viewport-fit=cover
- tests: AppShell banner, AvatarStack on ink

## Interfaces touched

None. AppShell props are unchanged.
