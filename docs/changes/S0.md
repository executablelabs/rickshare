# S0: scaffold monorepo

## Summary

Add the Bun workspace, shared v0 interfaces, Foundry project, API and merchant
skeletons, and heading-only React routes. Both development tracks now have their
package boundaries and a common local/CI check command.

## Files

- Root workspace scripts, lockfile, ignore rules, Biome and TypeScript configs.
- packages/shared: supplied schemas, Arc constants, exact USDC utilities and ABI generation.
- packages/contracts: pinned Foundry submodules and tested six-decimal mock USDC.
- apps/api: health endpoint, configuration, error/logging boundary and SQLite/Drizzle wiring.
- apps/merchants: health endpoint and validated static mock catalog.
- apps/web: Vite, Tailwind/design tokens, fonts, file routes, Query provider and typed API client.
- .github: CI workflow and PR template.
- Per-package .env.example files with every key from README.
- docs/DESIGN.md: supplied document relocated without content changes.
- docs/SETUP.md and docs/changes/S0-{390,1280}.png: setup notes and browser captures.

## Interfaces touched

- Introduce the supplied shared v0 schemas/types without changing their fields.
- Export Arc testnet configuration, ARC_USDC, USDC_DECIMALS, parseUsdc and formatUsdc.
- Export API AppType for Hono's type-only browser client.
- Introduce GET /health on both backends and GET /catalog on merchants.
- Introduce the five web routes listed in SCAFFOLD.md.
- Runtime integration credentials are optional for the scaffold; future tasks
  must require the credentials used by their features.
